# Effets sonores — combat au sabre laser

Trois effets originaux, prêts à être préécoutés ou importés dans Roblox Studio :

- `swing.wav` — balayage rapide et aérien, avec une légère chute de tonalité.
- `choc.wav` — impact métallique court, brillant et sec.
- `allumage.wav` — claquement électrique, montée du bourdonnement, puis bref son de verrouillage.

**Format :** WAV PCM, mono, 48 kHz, 16 bits.

## Import dans Roblox Studio

1. Dans Studio, ouvre **Asset Manager** puis **Bulk Import** (ou importe chaque fichier dans l’onglet Audio).
2. Une fois les fichiers publiés, récupère leur identifiant audio et référence-les avec `SoundId = "rbxassetid://ID"` dans tes objets `Sound`.

Les fichiers audio sont générés ici ; ils ne sont pas encore téléversés sur Roblox, donc ils n’ont pas encore de `SoundId`.
