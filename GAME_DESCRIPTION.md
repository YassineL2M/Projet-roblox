## 4. LES RÈGLES À RESPECTER (à lire une fois, ça évite un retrait)

| À faire | Pourquoi |
|---|---|
| Mettre les mots-clés **dans les 2 premières lignes** | C'est ce que Google/Roblox indexent sur l'aperçu de recherche |
| Écrire `saber` **et** `sabre` | Tu captures la recherche anglaise ET française |
| Parler de ce que le joueur **ressent**, pas de tes systèmes | « verrouillage de lames », pas « BladeLockController v2 » |
| Utiliser des séparateurs `⚔️ / 🔥 / 🏆 / ⌨️` | Le mur de texte ne se lit pas sur mobile, qui fait ~70 % du trafic Roblox |
| Terminer par les liens sociaux | Discord est autorisé dans les descriptions et c'est ton meilleur outil de rétention |

| À ne jamais écrire | Risque |
|---|---|
| `Lightsaber`, `Jedi`, `Sith`, `Force`, `Star Wars` | Marques déposées → retrait du contenu / DMCA |
| `Free Robux`, `R$ gratuit`, `Giveaway` | Détection automatique anti-scam, ton jeu est déclassé |
| `Pay to Win`, `P2W` | Même pour en rire, ça plombe la rétention |
| `Le meilleur jeu de sabre de Roblox` | Les joueurs sanctionnent l'auto-proclamation ; reste factuel |
| `Nouveau` en première ligne | Périme en 3 semaines. Écris ce que le joueur gagne, pas quand tu l'as ajouté |
| Promettre des features non développées | Faux contenu = signalements et avis négatifs |

**Note sur `sabre laser` dans les tags :** c'est le terme générique français (l'équivalent de « laser sword »), pas une marque — il a un gros volume de recherche. Si tu veux zéro risque, supprime-le : la description reste parfaitement valable sans.

## 5. OÙ METTRE LE RESTE (à ne pas entasser dans la description)

La description est lue en 8 secondes. Tout ce qui est long va ailleurs :

- **Tutoriel complet, commandes détaillées, liste des sabres** → un panneau dans le jeu au spawn, ou un système de menu « Aide ».
- **Patch notes / changelog** → ton Discord, ou un `DevProduct`/panneau « Update » dans le jeu.
- **Règles de la communauté** → un lien vers ton serveur Discord, pas 12 lignes de description.
